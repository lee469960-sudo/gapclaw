## Context

CodeAgent 已有运行事件流和最终结果 Markdown。平台生成的阶段标题已有中文映射，但 Claude Code 任务摘要来自模型输出，最终 Markdown 仍混用英文展示标签。审计证据必须可追溯，不能通过翻译改写命令、路径、哈希或错误标识。

## Goals / Non-Goals

**Goals:**

- 让 Claude Code 对用户输出的摘要、澄清和失败说明默认使用简体中文。
- 将最终 Patch 验证 Markdown 的展示标签统一为中文。
- 对上述行为增加确定性测试。

**Non-Goals:**

- 不翻译命令、文件路径、错误码、状态标识或 JSON 审计证据。
- 不新增语言选择、翻译服务或模型调用。
- 不改变 Runtime、Verifier、Sealer 或事件持久化协议。

## Decisions

### 在 Runtime 提示词中规定用户语言

在 Claude Code 调用提示词中加入简体中文输出要求，使模型生成的 `summary`、澄清和失败说明直接适配对话用户。相比事后自动翻译，该方式不会增加模型调用，也不会误译技术文本。

### 在最终 Markdown 格式层统一平台标签

仅替换固定展示标签为中文，状态标识与证据内容原样保留。相比递归翻译整个结果对象，这保持 API 和审计工件不变。

## Risks / Trade-offs

- [模型未完全遵守语言提示] → 平台固定标签仍保持中文；后续可基于实际模型输出补充受控降级文案，但本 change 不引入不可靠的机器翻译。
- [技术文本被误翻译] → 明确限定只翻译平台文案，不处理命令、路径、哈希、错误码和证据 JSON。

## Migration Plan

1. 发布后，新建 Code Run 的 Claude Code 摘要按新提示词输出中文。
2. 历史运行记录不迁移；重新打开时固定 Markdown 标签即时使用中文格式化。
3. 回滚时撤销提示词和固定标签改动，不影响已保存的 Run 与工件。
