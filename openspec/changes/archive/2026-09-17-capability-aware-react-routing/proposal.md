## Why

普通对话快速路径目前只依赖少量固定操作词，导致“帮我看看 OKX 当前持仓”这类明确需要外部能力的请求被误判为普通聊天。绑定 MCP 的名称、标签和描述已经存在，但没有参与进入 ReAct 的第一层路由，造成工具请求无法执行或返回不可靠的模型臆测。

## What Changes

- 在执行模式判定中加入已绑定 MCP 的名称、标签和描述能力提示，但不提前连接 MCP 或加载工具目录。
- 用户显式提到已绑定 MCP/工具名称时，强制进入 `task`/ReAct 路径。
- 用户请求与已绑定 MCP 能力元数据匹配时，即使没有固定操作词，也进入 `task`/ReAct 路径。
- 用户显式提到未绑定的工具或 MCP 时，仍进入任务路径并返回明确的未绑定提示，不生成普通聊天式臆测结果。
- 保持纯知识问答、解释和闲聊不因能力词重合而离开 `chat` 快速路径。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `conversation-execution-policy`: 执行模式路由增加绑定能力元数据和显式资源名称判定。
- `agent-runtime`: 在运行入口提供绑定 MCP 元数据、处理未绑定资源，并保持 MCP 工具目录惰性加载。

## Impact

- 影响 API Agent Runtime 的入口路由和 MCP 元数据读取。
- 影响普通会话与工具任务的模式指标及未绑定资源错误提示。
- 不改变 MCP 协议、工具授权、MCP 目录惰性加载或现有工具调用格式。
- 增加路由单元测试和 Agent Runtime 回归测试。
