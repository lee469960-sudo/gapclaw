## ADDED Requirements

### Requirement: 对话必须展示标准 local 发布准备与确认

系统 SHALL 在 CodeAgent 对话中展示标准 local 发布的仓库扫描、发布入口发现、应用依赖准备、一次确认、发布、验证和清理状态。展示内容 MUST 脱敏，不得显示秘密值或将未确认的候选命令表述为已执行。

#### Scenario: 发布准备完成

- **WHEN** 系统发现单一安全的发布入口并完成依赖准备
- **THEN** 对话显示中文的入口摘要、依赖准备结果和确认提示
- **AND** 在用户确认前不执行发布

#### Scenario: 发布完成

- **WHEN** 用户确认后发布进入终态
- **THEN** 对话显示中文的发布结果、验证摘要与恢复建议
- **AND** 不把失败或状态未知显示为成功
