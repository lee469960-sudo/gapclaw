---
name: planning-with-files
description: Keep task_plan.md, findings.md, and progress.md on disk for this change.
---

After OpenSpec artifacts exist, create and maintain:

- `.planning/<YYYY-MM-DD>-<change>/task_plan.md`
- `.planning/<YYYY-MM-DD>-<change>/findings.md`
- `.planning/<YYYY-MM-DD>-<change>/progress.md`
- `.planning/.active_plan` containing the directory name

Update progress after each phase. Log errors. Do not skip this because the session is unattended.
