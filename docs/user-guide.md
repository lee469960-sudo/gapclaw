# GAP 普通用户使用说明

面向平台内置角色 **普通用户（`user`）**。账号由管理员创建并分配该角色后即可登录。管理员若单独加了菜单权限，左侧可见项会比本文多；以你登录后实际菜单为准。

本文说明默认权限下能做什么、怎么做，以及看不到的功能该找谁。

---

## 1. 登录

1. 打开站点登录页，输入管理员给你的 **用户名**、**密码**。
2. 填写页面上的 **4 位验证码**（看不清可点验证码刷新）。
3. 登录成功后进入工作台。右上角显示当前用户名；点 **退出** 结束会话。

首次登录后请到 **系统管理 → 个人中心** 修改密码。

无菜单权限的页面会被拦到个人中心，这是正常行为，不是故障。

---

## 2. 你能看到哪些菜单

默认 `user` 角色只有这些入口：

| 分组 | 菜单 | 用途 |
|------|------|------|
| 智能平台 | 智能体 | 创建、配置 Agent，进入对话 |
| 智能平台 | 智能体群 | 多 Agent 协作群聊 |
| 智能平台 | Skills 市场 | 上传/查看可给 Agent 调用的技能包 |
| 智能平台 | MCP 市场 | 注册/查看外部工具（MCP） |
| 智能平台 | LLM 市场 | 配置模型与 API Key |
| 智能平台 | 模型路由 | 角色模型组与路由策略 |
| 智能平台 | 文件管理 | 平台文件目录的上传、下载、整理 |
| 系统管理 | 个人中心 | 改密码、个人 API Token |

列表页一般有 **所有 / 我的**：

- **所有**：你有权看到的（自己的 + 公开的 + 别人授权给你的）
- **我的**：你创建的

锁图标表示 **私有**，开锁表示 **公共**。

---

## 3. 可见范围（公共 / 私有）

多数资源（Agent、群、Skill、MCP、LLM 等）都有：

- **私有**：默认仅创建人可见；可在「授权用户」里填用户名（逗号分隔）分享给同事。
- **公共**：所有登录用户可见、可选用。

管理员能看到全部资源。普通用户看不到别人的私有项，除非被写进授权名单。

---

## 4. 智能体（日常主路径）

路径：**智能平台 → 智能体**。

### 4.1 创建 Agent

点 **+ 创建 Agent**，至少填写：

1. **名称、描述、系统提示词**（Agent 的人设与规则）。
2. **运行 Profile**
   - **Standard**：通用对话与工具调用（推荐日常使用）。
   - **Code**：绑定 Code 项目做改代码类任务。默认没有「Code Projects」菜单，项目需管理员建好并授权后才能选。
3. **LLM** 或 **模型路由策略**
   - 直接选一个 LLM（或 LLM 组）；或
   - 选一条路由策略，由策略按任务选模型。
   - Code Agent 只能绑「直接兼容 LLM」，不能走路由策略。
4. 按需勾选 **动作权限**（读文件、写文件、Shell、Skill、MCP、回忆等）。「输出最终回复」始终开启。
5. 按需绑定 **沙箱、MCP、HTTP 请求代理、Skill、知识库**。这些资源即使没有对应管理页，只要对你可见，仍可在表单里选用。知识库、沙箱、渠道等管理页默认不开放给普通用户，需管理员准备好公共/授权资源。
6. 设 **权限**：私有或公共。

保存后卡片上会显示绑定的 LLM、Skill / MCP / RAG 数量等。

### 4.2 开始对话

1. 点 Agent **名称**（卡片标题），打开会话列表。
2. 选已有会话，或新建会话（不同话题用不同会话，避免上下文搅在一起）。
3. 进入对话页：底部输入，**Ctrl+Enter** 或点 **发送**。
4. Agent 回复前会显示 **执行过程**（思考、工具调用步骤），可展开查看。
5. 运行中可点 **停止**。左侧是 **工作区**（Standard 为 Workplace，Code 为项目 Workspace），可勾选目录/文件作为本次上下文。
6. 对话框旁可 **上传附件** 到当前对话。
7. **备忘 / 查看总结 / 定时 / 清空对话** 在顶栏。

飞书等消息渠道若已由管理员绑到该 Agent，会话顶上会出现提示：手机端与机器人的对话会同步到同一会话。

### 4.3 编辑、记忆、定时、删除

- **编辑**：改提示词、模型、工具绑定、可见性。
- **记忆**：查看/维护 Agent 长期记忆（与单次会话历史不同）。
- **定时列表**（页头）：查看该账号相关的定时任务。
- **删除**：删掉 Agent 及其相关会话数据，操作前确认。

## 5. 智能体群

路径：**智能平台 → 智能体群**。

适合「一个问题需要多个专职 Agent」。

1. **+ 创建群**：名称、描述、公告、历史轮数、公共/私有。
2. **成员**：把已有 Agent 拉进群，可设群内别名。
3. 点群名称进入 **群聊**。
4. 用 **@** 指定谁干活：
   - **共享模式**：`@dba @分析 汇总本周数据` — 多个 Agent 收到同一任务。
   - **分派模式**：`@dba: 查表结构 @分析: 出结论` — 各做各的。
   - 不 @ 时默认通知全部成员。
5. **任务列表** 可查看群内任务进展。只有 **创建人** 能删除整个群。

## 6. Skills / MCP / LLM / 模型路由

对话能不能调工具、用哪家模型，取决于这些市场里的配置，以及 Agent 是否勾选了它们。

### Skills 市场

- **查看 / 下载** 你可见的技能包。
- **上传 Skill**（zip）后，在 Agent 里勾选才会在对话中调用。
- 仅创建人或管理员可编辑、删除。

### MCP 市场

- **+ 注册 MCP**：填写名称、协议、地址等。
- **工具**：探测该 MCP 暴露的工具列表。
- 注册后在 Agent 的 MCP 列表中添加。仅创建人可删除。

### LLM 市场

- **+ 添加 LLM**：名称、Provider、Base URL、API Key、Model。可用页面上的 Anthropic / MiniMax / Ollama 预设。
- 也可建 **LLM 组**（多个模型打包）。
- **测试** 用于确认 Key 与地址可用。
- Key 仅创建时完整填写；编辑时密码框留空表示不改。
- 设为 **公共** 后，同事才能把它绑到自己的 Agent 上。私有 Key 不要设成公共。

### 模型路由

- **角色模型组**：按角色（如 general、react_code）指定首选/回退模型。
- **路由策略**：指定 Router LLM 和要用的角色组，再在 Agent 上选择该策略。
- 只有声明了自动路由能力的 LLM 才能进对应角色组。

没有可用的 LLM 时，Agent 能创建但对话会失败。可先用管理员提供的公共模型，或自己添加一把 Key。

---

## 7. 文件管理

路径：**智能平台 → 文件管理**。

可浏览目录、新建文件夹、上传、下载、重命名、删除。双击文件夹进入下一级。

这是平台共享文件根目录，**不是**每人独立网盘。删除、覆盖会影响所有能进该页的人。个人草稿优先放在自己的目录名下，或放在 Agent 对话工作区。

Agent 对话里的 Workplace / Workspace 才是该 Agent 任务产生的文件，和本页不是同一棵树。

---

## 8. 个人中心

路径：**系统管理 → 个人中心**。

### 密码

旧密码 + 新密码 + 确认后保存。

### 个人 Token

用于脚本、CI、外部系统 **免浏览器登录** 调接口，权限与当前账号相同。

请求头：

```http
Authorization: Bearer <你的 Token>
```

触发一次 Agent 对话示例：

```bash
curl -G "https://<站点域名>/pages/api_agent_cgi.cgi" \
  --data-urlencode "agent_id=<AgentID>" \
  --data-urlencode "message=你好" \
  -H "Authorization: Bearer <你的 Token>"
```

Token 只显示一次或按页面保管；泄露后在个人中心删除并重新生成。它 **不能** 当作 Copilot / Cursor 的模型 API Key。

---

## 9. 默认做不到的事

下列能力不在默认 `user` 角色里，需要管理员授权或代为配置：

- **Code Projects、沙箱管理、RAG 知识库、HttpMCP、消息渠道**（飞书等）的管理页
- **SQL、远程终端、Docker、监控、发布管理**
- **站点配置、用户管理、角色管理**

因此：

- 飞书机器人进不了对话：找管理员检查渠道绑定与应用凭证，不是普通用户能在后台改的。
- 知识库检索没有结果：需要管理员建好语料并授权/公开，再在 Agent 上绑定知识库。
- 需要沙箱跑命令：使用已对你可见的沙箱；新建沙箱要有沙箱菜单权限。

管理员可以给单个账号加菜单，加完后以新菜单为准。

---

## 10. 推荐上手顺序

1. 登录 → 个人中心改密码。
2. **LLM 市场**确认至少有一个可用模型（公共或自备 Key）。
3. **创建 Standard Agent**，绑上该 LLM，提示词写清职责。
4. 点名称进入会话，发一句简单问题，确认能回复。
5. 需要工具时再上传 Skill / 注册 MCP，回到 Agent 编辑页勾选。
6. 多角色协作时再建 **智能体群**，把多个 Agent 拉进群后 @ 使用。

## 11. 常见问题

**列表是空的？**
别人的资源是私有且未授权给你。切到「所有」也只能看到公开项和自己的。请对方把可见性改为公共，或把你的用户名写入授权名单。

**能进 Agent 页但对话报错 / 一直不回？**
先看是否选了 LLM、Key 是否有效（LLM 市场点「测试」）。再看动作权限是否关掉了所需工具。执行过程卡片里的报错比聊天正文更具体。

**点了某个网址却跳回个人中心？**
当前角色没有该菜单权限。

**Code Agent 提示项目不可访问 / Manifest 未就绪？**
默认没有项目管理页。请管理员把项目配就绪并授权给你，或改用 Standard Agent。

**文件里的内容被别人改了？**
文件管理是共享目录。重要文件用独立子目录并约定命名，或只放在 Agent 工作区。
